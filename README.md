# webinar

Landing page for the free webinar "Why your ads are attracting the wrong leads".

A plain static site: open `index.html` or deploy the folder to any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages).

- Fonts: Mulish from Google Fonts. The licensed Aeonik files are fallback only and kept out of this repo (`fonts/` is gitignored).
- Registration form: posts to a GoHighLevel inbound webhook. See [GHL-SETUP.md](GHL-SETUP.md) and set the URL in `js/register.js`.
